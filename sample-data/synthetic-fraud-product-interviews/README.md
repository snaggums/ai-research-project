# Sky AIR synthetic fraud-product interviews

This package contains 15 synthetic user interview Transcripts created for research and demonstration. All Participants, organizations, providers, claim details, and scenarios are fictional. The files contain no real PII, PHI, claims, or investigative data.

- Product 1: Medicare Fraud Documenter, Sessions P1-S01 through P1-S05, interviewer Maya Chen
- Product 2: Medicaid Fraud Documenter, Sessions P2-S01 through P2-S05, interviewer Jesse Gilbert
- Product 3: Medicare Fraud Finder, Sessions P3-S01 through P3-S05, interviewer Kristina Snyder

Each product uses one shared core scenario with controlled Participant variations. Each Transcript contains 20 speaker turns and represents approximately 26 minutes of moderated prototype use.
