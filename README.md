# AI-Assisted UX Research Repository

A temporary working repository for the Qual AI Workspace MVP.

The project context from the starter package is stored under `project-context/`. Implementation will proceed in small sprint-sized vertical slices, starting with setup and Project CRUD before document upload, embeddings, evidence-backed themes, RAG chat, and exports.

## Current Status

- GitHub repo created as a private temporary project repo.
- Starter package context copied into `project-context/starter-package/`.
- Hackathon build standards copied into `project-context/build-standards/`.
- Empty `backend/` and `frontend/` folders created for the app implementation.

## Guardrails

- Use only public or synthetic data.
- Do not commit API keys, secrets, or `.env` files.
- Keep AI and vector storage providers behind swappable interfaces.
- Build one vertical slice at a time.
